# Student Grade Calculator

A beginner-level Python project that calculates student grades based on their marks using conditional statements.

## Objective

To calculate and assign grades to students using `if`, `elif`, and `else` statements based on predefined marks ranges.

## Technologies Used

- Python 3
- Jupyter Notebook

## Grading Logic

| Marks | Grade |
|------:|:-----:|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |
| Below 0 or above 100 | Invalid |

## Invalid Marks Test

- `-5` → Invalid
- `105` → Invalid
- `75` → B

## How to Run

1. Open the `Student_Grade_Calculator.ipynb` file in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. View the calculated grades.
